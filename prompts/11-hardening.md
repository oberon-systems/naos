# Prompt 11 — Production Hardening

Read `AGENTS.md`, `docs/02-threat-model.md`, and `docs/12-roadmap.md`.

Implement and verify:

- signed image verification;
- immutable digests;
- image scanning;
- resource quotas;
- QEMU/host sandbox hardening;
- token rotation;
- runner authentication;
- audit integrity;
- metrics;
- backups;
- migrations, covered by `11a-db-migrations.md`;
- alerting.

For every item document the threat, enforcement point, fail-closed behavior, tests, and operational guidance.
